# 🛡️ MetaCheck & Cleaner (Windows 11 Edition)

Приложение для **Windows 11** для инспекции, поиска, отображения на GPS карте и **очистки (полной или выборочной)** метаданных из фотографий (`.jpg`, `.jpeg`) и видеофайлов (`.mp4`).

## 💥 Возможности

1. **Чтение метаданных**:
   - **JPG Фотографии**: EXIF, IPTC, XMP, данные о камере, объективе, ISO, выдержке, диафрагме, дате и GPS-координатах.
   - **MP4 Видео**: QuickTime/ISO контейнеры, гео-теги (`©xyz`, `location`), кодеки, разрешение, длительность и битрейт.

2. **Интерактивная карта GPS (Leaflet + OpenStreetMap)**:
   - Автоматический вывод местоположения с меткой.
   - Кнопки **Zoom In (+)** и **Zoom Out (-)** для приближения/отдаления.
   - Обратное геокодирование (определение точного адреса/города).
   - Копирование координат в буфер обмена в 1 клик.

3. **Очистка метаданных (Полная или Выборочная)**:
   - **Полное удаление**: 100% очистка всех EXIF/QuickTime данных без перекодирования и без потери качества.
   - **Выборочное удаление**: Возможность точечно удалять отдельные теги (кнопка корзины напротив каждого тега) или только GPS данные.

4. **Экспорт данных**:
   - Поиск/фильтр по всем метаданным в реальном времени.
   - Экспорт в форматы **JSON** и **CSV**.

## 🛠️ Запуск проекта

### 1. Двойной клик на Windows
Просто запустите файл `start.bat`.

### 2. Через консоль / терминал
```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка проекта
npm run build
```

Приложение будет доступно по адресу: `http://localhost:3000`
